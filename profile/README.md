## What we're building

RChain Community develops systems around **Rholang, CBC-Casper, formal verification, distributed computation, and collective intelligence**.

The common direction:

**Make important claims executable, observable, falsifiable, and independently verifiable.**

## RChain in Rust

[`rchain-rust`](https://github.com/rchain-community/rchain-rust)

A Rust implementation of the RChain stack focused on:

- CBC-Casper consensus and finality
- Rholang concurrent execution
- validator and DAG behavior
- deterministic replay
- formal protocol laws
- runtime observability
- adversarial and testnet validation

## Quantum OS

[`quantum-os`](https://github.com/rchain-community/quantum-os)

A peer-to-peer architecture for collective intelligence across humans, AI agents, and independent compute nodes.

Current directions include:

- independent recomputation
- multi-rnode cross-checking
- falsifiable computation
- bounded agreement
- provenance and evidence
- human + AI collaboration

The goal is not another trusted central intelligence.

It is an environment where participants can **check one another's claims instead of trusting a single source of truth.**

> **A signature is not trust.**  
> **A hash proves integrity, not correctness.**  
> **A passing test is not a proof.**  
> **Missing evidence is not success.**
